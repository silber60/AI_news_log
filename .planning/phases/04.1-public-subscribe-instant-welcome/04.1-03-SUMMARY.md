# Phase 4.1 Plan 03: Live subscriber list and one-time import Summary

Once `UNSUBSCRIBE_ENDPOINT` is set, `mode=send` mails the deduplicated, not-unsubscribed active rows from the Sheet via `action=members`, failing closed before any SMTP connection. A dispatch-only `import-subscribers` workflow copies the old CSV readers into the Sheet in batches of 25 and logs counts only.

## What was built

- `members.fetch_subscribers`: POST `{action: members, key}` with `follow_redirects=True` and `LIST_TIMEOUT`. A transport error raises `DeliveryError("subscriber list <Class>")`. A non-200 raises `status=<n>`. Bad JSON, version not 1, a non-dict reply (including `{"error": "forbidden"}`) or `subscribers` missing or not a list raise `unreadable`. Rows are deduped by `strip().lower()`. Non-dict rows, non-string or invalid emails and duplicates count as skipped. Names are stripped, and a non-string name becomes empty. Zero valid rows raise `NoSubscribersError`. Nothing logs.
- `deliver._run_send`: endpoint None keeps `parse_subscribers(SUBSCRIBERS_CSV)`. With the endpoint set it reads the live list plus `fetch_unsubscribed`, both before any `build_message`, and ignores `SUBSCRIBERS_CSV`. The counts log line is unchanged.
- `importer.import_subscribers`: parses with `parse_subscribers` and posts `{action: import, key, rows: json}` in batches of 25 or fewer. Each reply is checked: version 1 and four non-negative ints. On any bad batch it raises `import <Class>`, `import status=<n>` or `import unreadable`, and the sums come back with `rows` and `skipped_rows`. `run_import()` raises `DeliveryError("unsubscribe endpoint not set")` before any env read or post, then reads `SUBSCRIBE_ADMIN_KEY` and `SUBSCRIBERS_CSV` through `deliver._env`.
- CLI `import-subscribers`: one line `import rows=%d added=%d existing=%d unsubscribed=%d skipped=%d skipped_rows=%d`. A failure prints `stage=import-subscribers error=<Class>`.
- `import-subscribers.yml`: workflow_dispatch only, workflow-level `contents: read` and no other permissions, group `newsletter` with cancel-in-progress false, the newsletter.yml SHA pins, and `secrets.` twice, only in "Import subscribers (counts only)". It has no artifact, echo, set -x or `${{` in run lines. The top comment says it runs once and is deleted in 04.1-06.
- `newsletter.yml` Deliver: `SUBSCRIBER_LIST_KEY: ${{ inputs.mode == 'send' && secrets.SUBSCRIBER_LIST_KEY || '' }}` next to `UNSUBSCRIBE_LIST_KEY`. The `SUBSCRIBERS_CSV` line stays for the transition.
- Tests: `test_members.py` (19), `test_import.py`, live-list cases in `test_delivery.py` (members/list both read, members failure stops before the list read, empty list, dedupe, CSV ignored, missing `SUBSCRIBER_LIST_KEY` posts nothing), `test_live_list_send_logs_counts_only` in `test_redaction.py`, and four new static guards plus `IMPORT` in the pin and run-line tests.
