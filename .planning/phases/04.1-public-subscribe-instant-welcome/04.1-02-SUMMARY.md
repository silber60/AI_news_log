## What was built

- `doPost` routing: list, then members, import and subscribe, then the unchanged token branch. The list line and both Phase 4 `done_` lines are byte-identical. `doGet` still never writes.
- `subscribe_`: honeypot `website` gives a silent ok. A bad email gives invalid. Missing consent or an unknown `cv` gives consent. The global hourly limit (30) and a lock timeout give busy. The per-id limit (3 per 6 h) gives a silent ok. Every other valid post gives ok after the locked upsert. No mail or fetch happens in the request.
- `upsert_`: one row per id. A new address is appended as `active` / `form`. An id on the unsubscribe list has that row deleted and the row reactivated (D-07). An already-active address only gets an empty name filled and is never queued.
- `enqueueWelcome_`: writes `q_<id>`, `w_<id>` and `wd_<yyyyMMdd KST>` (ids and counts only). Skips when a welcome was queued for that id in the last 24 h or 50 were queued today. Prunes old `w_` and `wd_` keys.
- `processWelcomeQueue`: idle runs return before taking the lock. Under `tryLock` it claims up to 20 `q_` keys by deleting them, then sends outside the lock. `sent` writes `welcomed_at`. `no_issue`, `shape` and `gone` drop the entry. `fetch` and thrown errors re-add `q_<id>` with attempt+1 under the lock, 3 runs in all. It never touches `w_<id>`.
- `sendWelcome_` / `fill_` / `greetingFor_` / `escapeHtml_` / `word_` / `b64_` / `utf8Len_`: fetches `SITE + 'welcome/latest.json'`, checks the payload, fills the slots with split/join (link first, then the HTML-escaped greeting), refuses anything that is not exactly one of each slot or is ≥ 92,160 B after the fill, and builds raw multipart MIME. The From display name and Subject use RFC 2047 words of at most 72 characters. The To line holds the address only. List-Unsubscribe and List-Unsubscribe-Post mirror `deliver.py` / `send.py`.
- `members_` returns active rows minus unsubscribed ids. `import_` normalizes rows, lets an earlier opt-out win, stores `consent_version = import` and `source = import`, and queues no mail. Both use `safeEq_` and refuse every key when the property is empty.
- `record_` deletes the subscribers row in the same lock after the Phase 4 append. It skips that step when the tab does not exist yet.
- `setup()` creates both tabs and their headers as plain-text columns and installs the trigger once. `selfTest()` checks token, greeting, escape, gmail, user, latest, tabs and trigger, and logs `PASS` or `FAIL <names>` (still the only `Logger.log`).
- Header comment and `test_public_functions_are_the_known_set` pin the public `google.script.run` surface: doGet, doPost, unsubscribe, setup, selfTest, processWelcomeQueue. setup, selfTest and processWelcomeQueue return nothing, and unsubscribe returns only a boolean.
- `appsscript.json`: Asia/Seoul, V8, STACKDRIVER, Gmail v1, USER_DEPLOYING / ANYONE_ANONYMOUS, and five oauthScopes including `script.scriptapp`.
- `README.md`: the one combined Korean setup. It covers the Sheet, Code.gs, the manifest, four generated values, five properties, setup with the trigger shown under 트리거, the 확인되지 않은 앱 screen, selfTest and the oauthScopes fallback. ## Deviations from Plan

### Auto-fixed / adjusted

1. **[Rule 2 - Correctness] Fixed-window rate-limit keys.** CacheService resets the TTL on every put, so a single `rl:all` key would stay alive under steady traffic. The keys carry an hour bucket (`rl:all:<n>`) and a 6 h bucket (`rl:<id>:<n>`), with the same 3600 and 21600 TTLs.
2. **[Rule 2 - Correctness] Lock via `tryLock(10000)` in subscribe_.** It returns false instead of throwing, so the plan's "caught timeout gives busy" needs no try/catch. The behavior is the same.
3. **[Rule 2 - Correctness] Per-run batch cap `WELCOME_BATCH = 20`.** It keeps a backlog inside the Apps Script execution limit. Unclaimed ids wait for the next minute.
4. **[Rule 2 - Security] Extra send-time checks.** `member_` re-validates the stored address with `normEmail_` before it goes into `To:`. `sendWelcome_` requires https `endpoint` and `unsubscribe_page`. `fill_` requires `[A-Z_]` slot names. An unparseable latest.json counts as `shape` (dropped), not a retry.
5. **[Rule 1 - Bug guard] Fill order.** `fill_` inserts the link before the greeting, so a name spelled like a slot cannot turn into a second fill.
6. `done_` got an optional title argument, so the subscribe HTML reply is titled `구독 신청 | 모닥로그 AI 리포트`. The Phase 4 calls are unchanged.

### Residual note

- Already-active and new submissions do the same locked lookup. Only a new or reactivated row adds one appendRow and one properties write, a small timing difference the plan accepts ("same read-modify-write shape").
