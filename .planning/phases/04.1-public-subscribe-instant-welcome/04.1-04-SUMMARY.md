## What was built

- `web.py`: `SUBSCRIBE_URL` is gone. `_home_context` reads `unsubscribe.UNSUBSCRIBE_ENDPOINT` at call time and adds `consent_version`. `PRIVACY_URL` is absolute. `_privacy_context` mirrors `_unsubscribe_context` (`../`, `../#archive`) and adds `subscribe_href = "../#subscribe"`. `build_site` writes `docs/privacy/index.html`, so the CLI logs `pages=5` with one issue.
- Form (both `subscribe` and `subscribe-bottom`): `method="post"`, `action` and `data-endpoint` set to the endpoint (both autoescaped), hidden `action=subscribe`, `fmt=html`, `cv=CONSENT_VERSION`, honeypot `website` in `div.hp[aria-hidden=true]` with `tabindex="-1"`, required `consent=yes` with the D-05 line (이름, 이메일 / 뉴스레터 발송 / 구독 해지 때까지) plus a link to `/privacy/`, and an empty `p.msg[role=status][aria-live=polite]`.
- Script, rendered once and only with the endpoint set: `URLSearchParams(new FormData(f))`, `fmt=json`, `fetch(data-endpoint, {method: "POST", body, redirect: "follow"})`, no Content-Type header, no JSON body, `textContent` only. `MSG` holds the four Code.gs REPLY strings verbatim plus `unknown` (Pitfall 9). The button is disabled while the request runs, and the form resets on `ok: true`.
- `.hp`, `.msg` and the other new form CSS live inside `{% if subscribe_url %}`. While the endpoint is None, Task 1 left `docs/index.html` byte-identical.
- `_base.html.j2`: the header comment now names both scripts. The nav 구독하기 uses `subscribe_href | default("#subscribe")`.
- `privacy.html.j2`: an h1 and ten h2 sections (처리 목적, 처리 항목, 보유 기간, 파기 방법, 제3자 제공, 처리를 맡기는 곳과 국외 보관, 정보주체 권리, 안전성 확보, 문의, 시행일). Each section has 1 to 3 해요체 sentences. The brand comes from `{{ brand }}` and 시행일 from `{{ consent_version }}`. The page has no address, no form and no script.

## Deviations from Plan

### Auto-fixed / adjusted

1. **[Rule 2 - Security] Reply-code lookup hardening.** The research sketch used `MSG[d.code] || MSG.busy`. The script instead uses `Object.prototype.hasOwnProperty.call(MSG, d.code)`, requires a string code and excludes `unknown`, so a key like `constructor` cannot reach the page. I wrote it as an `if`, not a ternary, so the "no ? in the script" ban stays simple.
2. **[Rule 2 - Correctness] Extra gated CSS.** Besides `.hp` and `.msg`, the gated block adds `.msg:empty { display: none }`, the consent link color and a disabled-button style. All of it sits inside `if subscribe_url`.
3. **Privacy wording on Sheet history.** The 보유 기간 section adds that the Sheet change history can keep deleted content for a while. Pitfall 11 says not to promise erasure, and stating the limit is more accurate than leaving it out.

Extra tests beyond the plan: the endpoint is autoescaped in both attributes (`&#34;`); no `name=` in any href/action/data-endpoint; the page has no `location` in the script; the privacy page has no form or script with the endpoint set or not; the template holds no literal consent version; the footer link is present on home, unsubscribe and privacy with the endpoint None and set; the committed privacy page exists and is address-free.
