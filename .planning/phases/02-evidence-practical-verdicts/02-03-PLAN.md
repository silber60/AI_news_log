## Phase Goal

**As a** subscriber, **I want to** see at a glance whether each model is usable in practice, **so that** I can decide what to try without reading license files, with verdicts decided by code from real HF/GitHub evidence and explained by Claude.

<objective>
Build the two Claude explanation calls: the 이번 주 트렌드 총평 and the batched 상업적 사용 / PoC reasons. Both follow the headline pattern (two attempts with feedback codes, code checks, non-fatal fallback). Claude only explains code facts; it never sets a verdict. Pipeline wiring is plan 02-05.

Purpose: ANLY-04 and ANLY-05 need guarded Claude text that can never invent a license, a model or a number.
Output: newsletter/stages/trend.py, newsletter/stages/notes.py, two prompts, output models, FakeAnthropic defaults, tests.
</objective>
