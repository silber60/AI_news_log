## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| workflow_dispatch form → runner shell | Owner-typed `week` string |
| GitHub secrets → steps | Secret values injected per step |
| runner → public logs / artifacts | World-readable output |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-23 | Elevation of privilege | `week` input script injection | high | mitigate | Passed via env only; static test forbids `${{` in run lines; Python validates |
| T-01-24 | Information disclosure | job-level secret env | high | mitigate | Delivery secrets step-scoped and mode-gated; static test enforces |
| T-01-25 | Tampering | GITHUB_TOKEN write scope | medium | mitigate | `permissions: contents: read`; no commit-back in Phase 1 (D-20) |
| T-01-26 | Tampering | third-party actions by tag | medium | accept | Tags from official orgs (actions, astral-sh); SHA pinning scheduled in Phase 5 (AUTO-03) |
| T-01-27 | Information disclosure | artifact contents | high | mitigate | Artifact path archive/ holds only the 구독자님 render; deliver writes nothing to archive; grep audit in Task 3 |
| T-01-28 | Denial of service / spam | accidental send | medium | mitigate | Default mode preview; send explicit; concurrency group |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | CI installs only from committed uv.lock (`--frozen`) |
</threat_model>
