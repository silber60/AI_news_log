## Phase Goal

**As a** newsletter owner, **I want to** trigger one manual GitHub Actions run that builds last week's HF Papers Top 10 issue and previews it or mails it, **so that** I can see the whole pipeline work end to end without leaking secrets or PII in the public repo.

<objective>
Harden the collection stage so the right week is always fetched completely: KST week math with override validation, week= paging with the required date= fallback (ISO week 53 and HTTP 400), weekend days queried, dedupe, in-week filter, bounded retries, fail-closed on empty, and deterministic Top N selection.

Purpose: COLL-01..04. The 2027-01-04 run targets 2026-W53, which HF rejects; without the fallback that Monday fails.
Output: hardened week.py / fetch.py / select.py with unit tests.
</objective>
