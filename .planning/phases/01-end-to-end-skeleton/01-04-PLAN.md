**As a** newsletter owner, **I want to** trigger one manual GitHub Actions run that builds last week's HF Papers Top 10 issue and previews it or mails it, **so that** I can see the whole pipeline work end to end without leaking secrets or PII in the public repo.

Output: render.py, two templates, tests.
</objective>
