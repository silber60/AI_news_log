## Phase Goal

**As a** newsletter owner, **I want to** trigger one manual GitHub Actions run that builds last week's HF Papers Top 10 issue and previews it or mails it, **so that** I can see the whole pipeline work end to end without leaking secrets or PII in the public repo.

Complete delivery: `send` mode from the SUBSCRIBERS_CSV secret with personalized greeting, robust CSV decoding, one EmailMessage per recipient over SMTP_SSL 465, a top-level error handler that keeps addresses/names/credentials out of public logs, the D-13 failure notice, and a test that the build step never touches delivery secrets.

Purpose: criteria 3 and 5, DLVR-01/02/03/06, D-02, D-03, D-13.
Output: delivery package, CLI handler, example CSV, tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub secret SUBSCRIBERS_CSV → process | PII enters memory |
| process → public Actions log / artifact | Anything printed is world-readable |
| process → Gmail SMTP | Credentials and recipient addresses leave |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-16 | Information disclosure | SMTP exception text | high | mitigate | DeliveryError(class + code) `from None`; top-level handler prints class only; tested with SMTPRecipientsRefused |
| T-01-17 | Information disclosure | Python tracebacks in CI | high | mitigate | Traceback only when NEWSLETTER_DEBUG=1 (never set in workflow) |
| T-01-18 | Information disclosure | SMTP protocol debug | high | mitigate | Debug output never enabled; grep gate in verify |
| T-01-19 | Tampering | header injection via subscriber name | medium | mitigate | Name used only in body; display_name strips control chars; EmailMessage rejects CR/LF |
| T-01-20 | Information disclosure | build step reading delivery secrets | high | mitigate | env-guard test + static check that only newsletter/delivery/ names them |
| T-01-21 | Information disclosure | committed subscriber data | high | mitigate | Only subscribers.example.csv committed; .gitignore covers subscribers*.csv |
| T-01-22 | Repudiation | partial send without ledger | low | accept | Single subscriber, manual send only until Phase 5 ledger (STATE.md) |
