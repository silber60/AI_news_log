## Interfaces this plan fixes (Wave 2 plans depend on these exact names)

- `newsletter.errors`: `PipelineError(Exception)` with class attribute `stage: str`; subclasses `InvalidWeekError` (stage "week"), `FetchError` and `EmptyFetchError(FetchError)` (stage "fetch"), `AnalysisInvalid` (stage "analyze"), `RenderTooLarge` (stage "render"), `NoSubscribersError` and `DeliveryError` (stage "deliver"). All are defined here; Wave 2 plans must not edit this file.
- `newsletter.week`: `KST = ZoneInfo("Asia/Seoul")`, `previous_iso_week(now: datetime) -> str`, `parse_week(s: str) -> tuple[date, date]` (raises `InvalidWeekError`), `week_label(mon: date, sun: date) -> str` returning e.g. `10/26(월) ~ 11/1(일)`.
- `newsletter.store`: `REPO_ROOT`, `TEMPLATES_DIR`, `PROMPTS_DIR`, `archive_root()` (env `NEWSLETTER_ARCHIVE_DIR`, default `archive`), `out_root()` (env `NEWSLETTER_OUT_DIR`, default `out`), `week_dir(issue_id) -> Path`, `write_json(path, obj)`, `read_json(path)`, `write_text(path, s)`, `write_current(issue_id)`, `read_current() -> str`.
- `newsletter.stages.fetch`: `fetch_week(issue_id: str, *, client: httpx.Client | None = None) -> FetchResult` where `FetchResult` has `entries: list[HfEntry]`, `raw: list[dict]`, `method: Literal["week","date"]`, `fetched_at: datetime`.
- `newsletter.stages.select`: `sort_key(entry)`, `select_top(entries, n: int = 10) -> list[HfEntry]`.
- `newsletter.stages.analyze`: `make_client()` (returns `anthropic.Anthropic(max_retries=4, timeout=300)`), `analyze_one(client, entry) -> ItemAnalysisLLM`, `analyze_items(entries, client) -> list[Item]`.
- `newsletter.stages.render`: `render_html(issue: Issue, greeting: str) -> str`, `render_text(issue: Issue, greeting: str) -> str`, `build_subject(issue: Issue, mode: Literal["preview","test","send"]) -> str`.
- `newsletter.pipeline`: `run_build(issue_id: str, *, http_client=None, claude_client=None) -> Issue` (writes all archive files and `current.json`).
- `newsletter.delivery.send`: `SENDER_NAME = "AI 주간 모델 브리프"`, `build_message(*, subject, sender_addr, to, text, html) -> EmailMessage`, `send_messages(messages, *, user, password)`; it references `smtplib.SMTP_SSL` through the module so tests can monkeypatch `newsletter.delivery.send.smtplib.SMTP_SSL`.
- `newsletter.delivery.deliver`: `run_deliver(mode: str) -> dict` (counts only).
- `tests/conftest.py` fixtures (Wave 2 plans use them and must not edit conftest): `FakeAnthropic` (scriptable per call; exposes `.messages.parse(**kw)` and `.beta.messages.parse(**kw)`, records `calls`), `make_parsed(...)` response builder (`stop_reason`, `parsed_output`, `stop_details`, `usage`), `FakeSMTP` (records `login` and `sent` messages, class-level `instances`), `hf_pages` (loads the three W44 fixture pages), `archive_tmp` (sets `NEWSLETTER_ARCHIVE_DIR`/`NEWSLETTER_OUT_DIR` to tmp_path), `issue_w44` (loads `tests/fixtures/issue_w44.json` as `Issue`).
