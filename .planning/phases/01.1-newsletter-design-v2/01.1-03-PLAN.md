## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HF paper/model API → enrich | Untrusted JSON: ids, dataset names, URLs |
| HF CDN → Pillow | Untrusted image bytes |
| Claude headline → Subject header and hero | Model-written text in a header |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01.1-08 | Tampering | model/space id used in a URL path | high | mitigate | Regex allowlist on ids before any request; invalid ids skipped and tested |
| T-01.1-09 | Information disclosure | image host / tracking pixel | medium | mitigate | Only https://cdn-uploads.huggingface.co/ candidates; ItemImage validator enforces the same host |
| T-01.1-10 | Denial of service | image header parse | medium | mitigate | Ranged GET of 64 KB, header-only Image.open, all Pillow exceptions → no image |
| T-01.1-11 | Spoofing | facts written by Claude | high | mitigate | Facts come only from enrich code; Claude output has no fact fields; absence stays 확인 필요, never False |
| T-01.1-12 | Tampering | prompt injection via titles into the headline | medium | mitigate | Input is already-checked Claude strings, URL-stripped and fenced; output is a closed emoji enum + checked hook; fallback on any failure |
| T-01.1-13 | Tampering | headline header injection | high | mitigate | _one_line + CR/LF check in write_headline, plus the build_subject guard from plan 04 |
| T-01.1-14 | Denial of service | HF outage blocks the newsletter | medium | mitigate | Enrich and headline are non-fatal; all-500 test proves the build passes |
| T-01.1-15 | Information disclosure | logs | medium | mitigate | Logs carry codes, ranks and attempt numbers only; tests capture logs and assert no ids, dataset names, hooks or titles |
| T-01.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages (Pillow added and locked in plan 02) |
</threat_model>
