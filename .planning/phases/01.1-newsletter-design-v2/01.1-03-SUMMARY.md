# Phase 1.1 Plan 03: HF Model Facts, Item Image and Claude Headline Summary

Code now fills 크기, 학습 데이터 and 공개 범위 from the HF paper and model APIs. It picks at most one 576-wide image per item from HF upload media, sized from the real aspect ratio. The issue headline comes from one checked Claude call, and any failure switches to the code fallback. HF or Claude problems in these steps never fail the build.

## What was built

- **enrich.py**:
  - For each item it sends `GET /api/papers/{id}`. The primary model is the linked model with the most downloads that is not private and has a valid id. That model gets one `GET /api/models/{id}?expand[]=safetensors&expand[]=cardData&expand[]=gated&expand[]=tags`.
  - **크기** comes from `safetensors.total`, formatted as B or M plus " 파라미터", with " (외 N개 모델)" when more than one model is linked.
  - **학습 데이터** comes from `cardData.datasets` (a string or a list), else from `dataset:` tags. It shows the first 3, then " 외 N개". Each id is cut at 40 characters with "…".
  - **공개 범위** joins 가중치 / 가중치(승인 필요), GitHub and 데모 with " · ".
  - The paper's `linkedDatasets` list is never read (`grep -c linkedDatasets` gives 0).
  - It sets `poc.has_*` and `hardware.param_count` only when the data is there, adds EvidenceLink entries for the model and the first Space, and leaves verdicts unchanged.
  - Requests get 2 attempts with tenacity, on transport errors, 429 and 5xx only. The wait multiplier is read at call time.
  - Problems are logged as `enrich=partial rank=N reason=<code>`. AssertionError is never caught.
- **Image**:
  - `pick_image_url` takes the first `https://cdn-uploads.huggingface.co/` URL that ends in png/jpg/jpeg/gif (case-insensitive).
  - `pick_image` sends `Range: bytes=0-65535`, needs status 200/206 and an image/png, image/jpeg or image/gif content type, and reads at most 64 KB.
  - It reads the size with Pillow, header only, and turns warnings into errors. It keeps the image only when w ≥ 576 and 1.3 ≤ w/h ≤ 3.5, and sets height = round(576·h/w).
  - Otherwise it logs `image=none rank=N reason=<code>`. Nothing is base64-encoded.
- **fetch.py**: `_PAPER_KEYS` keeps `mediaUrls`.
- **pipeline.py**: runs `enrich.enrich_items(items, top, client=http_client)` after analyze, and builds `Issue(headline_ko=headline.write_headline(items, client))`.
- **headline.py and prompts/headline.md**:
  - The input is an `<items>` block with ranks 1-3: title_ko, ai_type, summary_ko and summary_lines_ko[0]. These are URL-stripped, `<items>`-tag-stripped and made one line.
  - The output format is HeadlineLLM.
  - `check_hook` checks:
    - length (24 or less)
    - emoji ranges U+2600–U+27BF, U+1F000–U+1FAFF, U+FE0F and U+200D (Hangul passes)
    - URLs and CR/LF
    - hype words
    - clickbait words that are not in the input
    - authorship wording
  - It retries once via `_with_feedback`, then falls back.
  - It logs only `headline=claude attempt=N` or `headline=fallback reason=<code>`.
- **analyze._request** takes `system=` and `output_format=` keyword arguments. The defaults keep the analysis call byte-identical, and the headline call shares the beta-fallback downgrade.

## Deviations from Plan

1. **[Rule 3 - Blocking] CDN route moved from Task 1 to Task 2.**
   - In Task 1 nothing requests the CDN yet. A registered route that is never called makes every `assert_all_called=True` run_build test fail (e2e, render, select).
   - The route was added in Task 2 together with the image code (1118b0c).
2. **[Rule 1 - Test update] Two more call-count assertions.**
   - `test_bad_request_downgrades_to_plain_parse` and `test_sdk_type_error_downgrades_to_plain_parse` in test_analyze.py expected `["beta"] + ["messages"] * 10`.
   - With the headline call it is now `* 11`. This also shows that the downgrade covers the headline (c7dcfe6).
3. **[Rule 2 - Test helper] Extra conftest options.** `mock_hf_week(..., enrich_fail=True)` drives the all-500 build test. `mock_enrich` takes `papers=`, `models=` and `image=` overrides for single-case tests.
4. **[Rule 2 - Hardening] Two more input guards.** The paper id is checked against `^\d{4}\.\d{4,5}$` before the paper URL is built, and `<items>` tags are stripped from the headline input so a title cannot close the fence.
5. **Fallback wording.** The plan-01 `fallback_headline` format ("🧠 X 등 이번 주 AI 모델 10") is kept. The research's "이번 주 1위는 … 외" wording is not used.
6. **Verify path.** The `<automated>` commands were run in the worktree, not the main checkout, as the orchestrator instructed. gsd-tools steps were skipped because node is not installed. STATE.md and ROADMAP.md were not touched.
