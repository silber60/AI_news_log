# 04.2-01 Summary: send from the owner's domain through Resend

Inserted as a quick phase, without a separate plan, before Phase 5 execution. Commit cd3f780.

## What changed
- send.py:
  - SMTP goes to `smtp.resend.com:465` with login `resend`. The `SMTP_PASSWORD` secret now holds the Resend API key.
  - From is `모닥로그 AI 리포트 <newsletter@modaklog.characterplanner.co.kr>` (`MAIL_DOMAIN`, `MAIL_FROM`). Message-ID uses the sending domain.
  - The owner's Gmail (`SMTP_USER` secret) is the Reply-To and stays the List-Unsubscribe mailto, so 수신거부 replies still reach the owner.
  - `send_messages(messages, *, password, pause)`: the `user` argument is gone, because the login name is fixed.
- Code.gs: when the `RESEND_API_KEY` script property is set, `sendWelcome_` posts to `https://api.resend.com/emails` with the same From, Reply-To and List-Unsubscribe headers. A non-2xx reply throws and is retried like a Gmail error. The Gmail advanced service remains the fallback.
- Workflow env names are unchanged: `SMTP_USER`, `SMTP_PASSWORD`, `TEST_RECIPIENT`.

## DNS (Cloudflare, characterplanner.co.kr)
These records are live: `resend._domainkey.modaklog` TXT (DKIM), `send.modaklog` and `rsend.modaklog` CNAME (Resend Forge), and `_dmarc` TXT.
