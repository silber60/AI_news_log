## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HF githubRepo URL → raw.githubusercontent.com request | Untrusted string becomes a request path |
| README markdown → image candidates | Untrusted repo content |
| Image host → Pillow | Untrusted bytes |
| enrich logs → public Actions logs | World-readable |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01.2-10 | Spoofing / SSRF | parse_repo, README fetch | high | mitigate | Owner/repo regex, ".." rejected, fixed host raw.githubusercontent.com, follow_redirects=False |
| T-01.2-11 | Denial of service | README read | medium | mitigate | Streamed read capped at 256 KB; 15 s timeout; README never sent to Claude |
| T-01.2-12 | Tampering | README image URLs | medium | mitigate | Host allowlist, no query/fragment, ≤ 300 chars, no redirecting or signed hosts, schema validator re-checks |
| T-01.2-13 | Denial of service | Pillow parse | medium | mitigate | 64 KB header only, warnings as errors (decompression bomb), every Pillow error = no image |
| T-01.2-14 | Information disclosure | enrich logs | low | mitigate | Reason codes and ranks only; caplog tests assert no URL text |
| T-01.2-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages (regex + html.unescape + existing httpx/Pillow) |
</threat_model>
