## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-16 | Tampering | DOM XSS via t | medium | mitigate | Regex fullmatch on hex before use; .value only, no innerHTML; endpoint via autoescaped data- attribute |
| T-04-17 | Tampering | prefetch or auto-submit unsubscribes | medium | mitigate | GET writes nothing; no .submit(); POST only from the button (D-12); test forbids ".submit(" |
| T-04-18 | Tampering | CSRF from a third-party page posting a known token | low | accept | Needs the victim's token, which only their mail holds; impact is one unsubscribe (research Security Domain) |
| T-04-SC | Tampering | npm/pip/cargo installs | high | mitigate | No installs |
