## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Anyone on the internet → Apps Script /exec | Anonymous GET/POST (Access: 모든 사용자) |
| Deliver step → Apps Script list | Key-protected read of unsubscribe ids |
| Repo (public) ↔ secrets | Code.gs and README are public; secrets live only in script properties and Actions secrets |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-08 | Spoofing | forged unsubscribe tokens | medium | mitigate | HMAC needs TOKEN_SECRET; random ids match no subscriber; TOKEN_RE on every input |
| T-04-09 | Information disclosure | list endpoint scraping / key leak | medium | mitigate | LIST_KEY in POST body only, safeEq_ constant-time compare, ids are not reversible without the secret; DeliveryError text has no key or URL query |
| T-04-10 | Tampering | scanner prefetch unsubscribes | medium | mitigate | doGet and the Pages page never write; record_ runs only from doPost or google.script.run after a button press (D-12) |
| T-04-11 | Information disclosure | addresses in the Sheet or repo | high | mitigate | Sheet stores only the 32-hex id, time and via; Code.gs holds no secrets; tests and greps forbid addresses in logs |
| T-04-SC | Tampering | npm/pip/cargo installs | high | mitigate | No installs (httpx, respx already locked) |
</threat_model>
