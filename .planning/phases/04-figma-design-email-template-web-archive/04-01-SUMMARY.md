# Phase 4 Plan 01: Web archive tracer Summary

A mode=send run now copies the issue to data/issues/<id>.json, regenerates the de-personalized issue page and a home page with `<section id="archive">`, commits them in one push and deploys docs/ to GitHub Pages in the same run. Every email links 웹에서 보기 to the fixed issue URL and 지난 호 보기 to `#archive`.

## What was built

- **render.py**: `WEB_URL` removed. `SITE_URL = "https://silber60.github.io/AI_news_log/"`, `ARCHIVE_ANCHOR = "#archive"`, `issue_url()`, `archive_url()`. `_context(..., *, web=False)` passes `web`, `site_url`, `issue_url`, `archive_url`. `render_web_issue(issue)` renders email.html.j2 with `DEFAULT_GREETING` (imported from delivery.subscribers) and web=True, with no inlining and no byte gate. `render_html`/`render_text` signatures unchanged.
- **email.html.j2 v9 / email.txt.j2 v8**: header 웹에서 보기 → issue_url (email only). Email footer keeps the 수신거부 reply line and adds 웹에서 보기 · 지난 호 보기. Web footer: fixed 구독 해지 sentence and 지난 호 보기 only. Text part writes both URLs out.
- **newsletter/web.py**: `publish` (first send wins), `load_issues` (validated, newest first, one bad file raises), `build_site` (all issue pages and home, deterministic, never writes docs/assets).
- **CLI**: `publish --mode` (non-send logs `web=skipped mode=<mode>`; send logs `web=published|exists issue=<id>` then `web=site pages=<n>`), `site` (regenerate only). Logs carry ids and counts only.
- **docs/index.html**: generated by `uv run python -m newsletter site` (zero issues, empty state "아직 발행된 호가 없어요.").
- **Workflow**: `record-topic` job replaced by `publish` (contents: write, send on main only, persist-credentials false, record-topic + publish steps, one "Commit record and pages" step, then upload-pages-artifact docs/). New `deploy-pages` job (pages: write, id-token: write, environment github-pages, concurrency pages, no checkout, no secrets). New `pages.yml` (push to main on docs/** + workflow_dispatch; build + deploy). The build step still holds exactly one `secrets.` reference.
